01 场景锚定

场景锚定

S25 机加车间案例库与复发预警（86.6）vs S27 集团知识网络（85.3，差 1.3<3 → D2 均 4 平 → 取总分）；S26 注塑配方（83.3）。

选 S25：与 S22/M1-B 同车间同数据流（异常关闭记录直接入案例库）；"经验沉淀"正面回应赛道关键词。落选理由：S27 多厂区数据组织复杂且 Demo 单薄；S26 商业调机方案多。

对应 PRD §1 场景锚定

02 目标用户与痛点

目标用户与痛点

  • 用户：设备/质量/工艺工程师（案例生产与消费）、车间主任（复盘决策）。
  • 痛点（量化假设）：同类异常复发率 ≥30%（复盘缺失口径）；老师傅离职带走经验；月度复盘报告无人愿写（≥4 小时/月）。
对应 PRD §3 用户与痛点

03 产品定位

产品定位（一句话）

车间的记忆官：每次异常自动变结构化案例，复发早知道、预案自动备好、SOP 修订有依据——把"经验沉淀"从人工义务变成系统飞轮。

对应 PRD §2 产品定位

04 Agent 编排 · 微循环与宏门禁

Agent 编排（3 Agent）

Agent职责（微循环内自主）
案例结构化 Agent异常关闭记录 → 结构化案例（现象/根因/措施/备件/耗时/证据）
复发监测 Agent新异常早期特征匹配历史案例 → 相似度排序 → 预案推送
知识运营 Agent月度 Pareto、复发模式聚类、SOP 修订建议、知识缺口提示
  • 微循环定义：异常关闭→结构化→入库；新异常早期→匹配→预案推送，双微循环自主运转。
  • 宏门禁点：①预案采纳（工程师）②SOP 修订（主管审批）③知识库对外共享（若有）。
对应 PRD §4 Agent 编排

任务闭环 7 步映射（手册 8.2）

输入=异常关闭事件与处理记录 → 意图理解=案例要素抽取与分类 → 任务规划=结构化与入库计划 → 能力调用=向量检索/规则匹配/统计工具 → 结果交付=案例条目+预案推送+复盘报告 → 验证反馈=复发命中率统计与采纳率 → 安全边界=建议域，SOP 修订走既有审批流。

对应 PRD §5 闭环 7 步（手册 8.2）

06 数据策略 ＆ 评测指标

数据策略

由 S22/M1-B 事件流积累 + 预置 100 条历史案例（含 3 组复发剧本：同类故障复发、同部件周期性失效）；向量检索与 CBR 用开源组件；模拟逻辑写入合规文档（FAQ Q7）。

评测指标

复发剧本 Top-3 命中率 ≥75%；预案采纳率（人工评分 ≥4/5）；案例字段完整率 ≥95%；月度复盘报告生成 ≤5 分钟。

对应 PRD §6 数据策略 ＋ §7 评测指标

07 安全合规口径

安全合规口径

知识建议域：不替代 SOP 审批与专业判断（手册 9.3）；案例不含真实人员绩效评价（避免 HR 敏感）；模拟数据披露。

对应 PRD §8 安全合规

09 开源复用物 ＆ 风险对策

开源复用物

异常案例库 schema、CBR 检索模板、复盘报告生成器、复发剧本模拟器。

风险与对策

冷启动无案例 → 预置 100 条+结构化校验；案例质量差 → 字段完整率门禁+人工抽检队列；价值感滞后 → 用"复发命中"对比演示（无飞轮 vs 有飞轮响应差异）。

对应 PRD §10 开源复用 ＋ §11 风险

10 参赛简介（≤500 字 · 八要素）

参赛简介（≤500 字，八要素）

项目名称：车间记忆 ShopMemory——异常案例沉淀与复发预警智能体。

行业赛题：AI+工业制造。目标用户：机加车间设备、质量与工艺工程师及车间主任。

核心问题：同类异常反复发生，处理经验随人员流失，复盘无人写、知识不沉淀。

解决方案：三 Agent 飞轮——案例结构化 Agent 将每次异常关闭记录转为含现象、根因、措施、备件、耗时的结构化案例；复发监测 Agent 在新异常早期匹配历史案例并推送预案；知识运营 Agent 生成 Pareto、复发模式与 SOP 修订建议。

创新点：把"经验沉淀"从人工义务变成自动飞轮；复发时预案先行；预案采纳与 SOP 修订由工程师与主管拍板。

开放/复用价值：开源案例库 schema、CBR 检索模板与复盘生成器，可挂接任意工单系统。

当前进展：方案设计完成，预置案例集制作与原型开发中，提交时附飞轮回放演示。

对应 PRD §12 参赛简介
