02 目标用户与痛点

目标用户与痛点

  • 用户：采购员、SQE（供应商质量工程师）、物控。
  • 痛点（量化假设）：供应商突发断供平均在交付逾期后才被发现；单一供应商依赖（订单集中度）无人量化；应急切换无预案、无影响分析。
对应 PRD §3 用户与痛点

03 产品定位

产品定位（一句话）

采购的供应哨兵：多源信号持续聚合→风险评分→分级预警→替代候选与切换影响分析备好，换不换供应商、催不催单由人拍板。

对应 PRD §2 产品定位

04 Agent 编排 · 微循环与宏门禁

Agent 编排（3 Agent）

Agent职责（微循环内自主）
信号聚合 Agent交期延误/物流事件/质检退货率/订单集中度四源事件流→标准化与去重
风险评估 Agent规则+时序综合评分，输出 R/G/Y 分级与趋势、归因明细
备选准备 Agent替代供应商候选清单+切换影响分析（在途订单/模具/认证周期/成本）
  • 微循环定义：事件流入→评分→分级预警→备选包生成，全程自主值守。
  • 宏门禁点：①切换供应商（采购决策）②催单/索赔（商务动作）③高成本预案（如紧急空运）审批。
对应 PRD §4 Agent 编排

对应 PRD §5 闭环 7 步（手册 8.2）

06 数据策略 ＆ 评测指标

数据策略

事件流模拟器生成四源信号（预埋 3 组风险剧本：交付持续滑坡、物流中断、集中度超标）；供应商库模拟 10 家（含交期分布/历史绩效/风险分）；公开物流事件仅作风格参考。模拟逻辑写入合规文档（FAQ Q7）。

评测指标

预埋风险剧本检出率 3/3；预警提前量（较"逾期才发现"基线，模拟口径 ≥5 天）；误报 ≤1 次/模拟周；备选包字段完整率 100%（人工抽检）。

对应 PRD §6 数据策略 ＋ §7 评测指标

安全合规口径

商业建议域：不自动下达任何采购或商务变更；评分归因可解释可追溯（手册 8.1-6、9.3）；模拟数据无真实供应商信息。

10 参赛简介（≤500 字 · 八要素）

参赛简介（≤500 字，八要素）

项目名称：供脉哨兵 SupplySentinel——供应商多源风险预警智能体。

行业赛题：AI+工业制造。目标用户：机械/汽配厂采购员与供应商质量工程师。

核心问题：供应商突发断供发现晚、应急无预案、订单集中度风险无人盯。

解决方案：三 Agent 值守系统——信号聚合 Agent 标准化交期延误、物流事件、质检退货与订单集中度四源信号；风险评估 Agent 输出分级评分、趋势与归因；备选准备 Agent 生成替代供应商候选与切换影响分析（在途订单、模具、认证周期）。

创新点：微循环自主（聚合-评分-备包）、宏流程门禁（切换供应商、催单、索赔由采购拍板）；与齐套计划、缺料请购构成同厂闭环，风险直接驱动行动。

开放/复用价值：开源风险信号 schema、事件模拟器与评分模板，可迁移至多行业采购域。

当前进展：方案设计完成，原型开发中，提交时附回放演示。

对应 PRD §12 参赛简介
