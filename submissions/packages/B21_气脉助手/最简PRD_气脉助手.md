# 最简 PRD：气脉助手 AirFix（空压机售后报修全旅程）

## 1. 一句话定位
空压机厂商的售后服务台：客户拍照报修，系统多轮问诊翻译症状、给出带依据的诊断、查备件、起草工单，修完自动归档案例——下次同样的报修，答案已经在库里。核心动词：**问诊**。

## 2. 用户与痛点
- 用户：厂商售后工程师、客户工厂设备管理员。
- 痛点（量化假设，交付前校准）：
  1. 报修响应 ≥24 小时，专家差旅约占售后成本 30-40%；
  2. 修完知识蒸发，同故障重复诊断；
  3. 批次性故障靠客户投诉倒逼才发现。

## 3. 核心流程
**微循环（自动执行）**：报修（照片/语音/故障码）→ 设备档案带出（装机信息/保养计划/保内保外规则判定）→ 多轮问诊（状态机约束，最多三轮澄清，信息不足转人工）→ 诊断 Top-3（每条附**诊断依据**：手册段落坐标、相似维修工单、照片标注，另列"待确认项"）→ 备件库存查询 + 工单起草 + 派单建议 → 结案 → **维修案例**归档。同型故障 30 天计数（纯规则）超阈 → 一键生成批次线索报告。
**宏门禁（人工拍板）**：诊断确认＝工程师；高压电气/压力容器作业＝转持证人员；案例入库＝存档审核；批次深查与客户通报＝厂商管理层。

## 4. MVP 范围
做：
1. 双端：客户报修端 + 工程师工作台；
2. 问诊状态机 + 档案上下文（保内判定为规则）；
3. 诊断证据卡（依据引用 + 待确认项 + 置信度分级）；
4. 备件查询 + 工单包 + 缺货请购提醒卡；
5. 案例归档 + 同型热度规则 + 批次线索报告。
不做：
1. 设备远程控制与参数下发；
2. 真实厂商系统对接（工单导出为标准格式即可）；
3. 预测性维护与故障预测；
4. 备件自动下单。

## 5. 数据与评测
- 数据：自建 2-3 本模拟设备手册（规避版权）+ 200 条模拟维修工单（预埋 2 组批次热度剧本），生成逻辑披露。
- 指标：① Top-3 诊断命中率 ≥70%（ground truth 工单集）；② 备件建议准确率 ≥90%；③ 批次线索检出 2/2、误报 ≤1 次/月。

## 6. 边界与合规
诊断是"建议+待确认项"，确认者是工程师；高危作业强制提示转持证人员（手册 9.3、FAQ Q13）；手册与工单均为自建模拟并披露（FAQ Q7）。

## 7. 里程碑
- 复赛（9.3）：报修→问诊→诊断→备件→工单→归档一条链可运行（双端）。
- 决赛（9.22）：完整旅程 + 失败分支（信息缺失/检索未命中/转人工）+ 批次线索彩蛋。
