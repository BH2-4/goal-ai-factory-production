# 最简 PRD：安灯中枢 AndonCop（车间异常值守调度台）

## 1. 一句话定位
机加车间的异常值守调度台：把设备报警、质量超标、缺料预警从"现场吼人+微信群"变成自动分诊、按技能派单、超时升级、结案归档的闭环。核心动词：**调度**。

## 2. 用户与痛点
- 用户：班组长、维修工程师、车间主任（机加车间，离散制造）。
- 痛点（量化假设，交付前用访谈校准）：
  1. 异常平均响应 ≥30 分钟，超时无兜底升级；
  2. 处理记录散落微信群，事后无结构化数据；
  3. 同类异常复发率 ≥30%，复盘缺失。

## 3. 核心流程
**微循环（自动执行）**：事件流入（遥测越限/质检超标/缺料预警/人工拍照上报）→ 分诊（规则优先，AI 仅辅助分类，定级 P1-P3）→ 派单（技能矩阵×班次×当前负荷）→ SLA 计时，超时逐级升级并生成**升级凭证**（超时时长/同类历史均值/当班负载）→ 结案 → **异常案例**自动归档；同型事件再现时匹配 Top-3 历史案例并推送预案。
**宏门禁（人工拍板）**：停线建议确认、结案确认＝主管；预案采纳＝工程师；SOP 修订＝主管审批。

## 4. MVP 范围
做：
1. 事件引擎 + 分诊（含人工拍照上报通道）；
2. 技能矩阵派单（含备份人选）；
3. SLA 升级链（P1 15min/P2 30min/P3 4h，可配置，凭证自动生成）；
4. 结案案例归档 + 复发匹配推送；
5. 三端：班组长哨位屏 / 工程师移动端 / 主任复盘端（Pareto）。
不做：
1. 设备控制与停线执行（只建议不执行）；
2. 预测性维护模型（不预测，只响应）；
3. 多厂区/多租户；
4. 真实 MES 深度对接（仅留事件源接口）。

## 5. 数据与评测
- 数据：UCI AI4I 2020（1 万条合成、5 类故障模式）映射设备告警流；自建排班/技能矩阵/事件剧本（含 3 组复发剧本），生成逻辑披露。
- 指标：① 分诊准确率 ≥85%（500 条标注事件集）；② SLA 升级遗漏 =0（程序断言判卷）；③ 复发 Top-3 命中 ≥75%。

## 6. 边界与合规
仅作辅助参考，不控制真实设备，不替代现场安全生产决策与专业判断（手册 9.3、FAQ Q13）；案例只记事不记人；公开+模拟数据并披露（FAQ Q7）。

## 7. 里程碑
- 复赛（9.3）：事件回放模式一条链可运行（AI4I 驱动，分诊→派单→升级→归档）。
- 决赛（9.22）：实时注入事件 + 照片分诊 + 复发对比演示（同一故障首次 40 分钟、二次 5 分钟）。
