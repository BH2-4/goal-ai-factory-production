## 三、Agent 契约细化（4 Agent + 记忆检索）

- **分诊 Agent**：输入=事件（遥测越限/质检超标/缺料预警/人工拍照上报）；输出=类型+严重度 P1-P3+影响面初判；失败分支=无法分类 → 默认 P2 进人工分诊队列
- **调度 Agent**：输入=分诊结果+技能矩阵+班次+当前负荷；输出=派单+备份人选+SLA 时钟；工具=排班表/备件库存查询
- **跟踪 Agent**：输入=工单状态流；输出=超时升级（附证据包）；失败分支=通知通道失败 → 降级看板红条+短信
- **复盘 Agent（含记忆层）**：输入=结案记录；输出=案例卡+月度 Pareto+聚集度预警；失败分支=字段缺失 → 打回补录（不阻塞结案）
- **案例匹配（检索服务）**：输入=新事件特征向量；输出=Top-3 历史案例+预案；人工确认后推送当班工程师

## 五、评测集设计

- 分诊准确率 ≥85%：AI4I 映射事件集 500 条（ground truth 标注）
- SLA 违反 0 / 升级遗漏 0：模拟回放断言（程序判卷）
- 响应时长较人工分诊基线 ↓≥40%（模拟对照）
- 复发命中 Top-3 ≥75%：预置 100 案例库 + 3 组复发剧本
- 冷启动导入字段准确率 ≥85%（手写样例 20 份）

## 七、答辩 QA 预案

1. **和 MES/Andon 系统比？** 不做设备侧采集，做"事件之后的调度与知识"；可对接既有 Andon 事件源
2. **AI 到底在哪？** 调度与升级全是规则；AI 只做三件事：分诊辅助分类、升级证据包叙述、案例卡归因润色——克度可控可审计
3. **数据？** AI4I 公开数据集+模拟事件流，剧本与生成逻辑全披露（FAQ Q7）
4. **老产线没数字化？** 支持人工上报（拍照+表单）作事件源；记忆层数据来自本系统工单——软件层自产，不动产线（D-011 回应）
5. **停线谁负责？** 系统只建议+催办，停线决策人拍板（手册 9.3 / FAQ Q13）
