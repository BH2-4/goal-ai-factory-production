# PRD：M2-A 报修-修复-沉淀主链（P2 装备售后全旅程闭环）

> 版本 v1.0 ｜ 2026-08-14 ｜ 锚定场景 S01（评分 89.8，见 `docs/research/场景调研_27选9.md`）

## 1. 场景锚定
三场景对比：S01 空压机售后（89.8）＞ S02 注塑机（84.0）＞ S03 数控机床（82.5）。
**选 S01 理由**：空压机是"IoT 远程监控+售后服务合同"渗透率最高的通用装备；耗材型工单（滤芯/油品/冷却器）高频且结构化程度好，天然适合案例沉淀；与 M2-B（机队哨兵）、M2-C（装机档案）同数据域。落选理由：S02/S03 竞争密度更高且与 P2 其他 MVP 协同弱。

## 2. 产品定位（一句话）
空压机厂商的随身售后专家：客户拍照报修，Agent 自主跑完 问诊→检索→备件→工单→指导→沉淀 全链，把每次维修变成厂商的知识资产。

## 3. 目标用户与痛点
- 用户 A：厂商售后工程师（派单、远程支持、备件建议）；用户 B：客户工厂设备管理员（报修、日常保养）。
- 痛点（量化假设，实现期校准）：响应时长 ≥24h；专家现场差旅占售后成本约 30-40%；同一故障重复诊断率高；维修记录非结构化，知识随人流失。

## 4. Agent 编排（4 Agent）
| Agent | 职责（微循环内自主） |
|---|---|
| 问诊 Agent | 多轮交互式故障树（症状+照片识别部件/状态）、澄清缺失信息 |
| 知识检索 Agent | 手册 RAG + 历史工单 CBR（Top-K 相似案例带证据） |
| 备件/工单 Agent | 备件 BOM 匹配与库存查询、工单草案、工程师技能匹配建议 |
| 沉淀 Agent | 维修记录→结构化案例（现象/根因/措施/备件/耗时）→回流知识库 |

- **微循环定义**：单票报修从受理到"工单+指导+案例草稿"生成，全程无人工介入。
- **宏门禁点**：①诊断确认（工程师）②高危操作（电气/压力容器作业）强制转持证人员提示 ③案例入库存档审核。

## 5. 任务闭环 7 步映射（手册 8.2）
输入=照片/语音/故障码报修 → 意图理解=故障现象分类与紧急度 → 任务规划=问诊路径+检索计划 → 能力调用=手册/案例库/备件库/工单系统 API → 结果交付=诊断结论+备件单+工单+分步指导 → 验证反馈=维修结果回填+满意度+案例命中统计 → 安全边界=高危分级提示与人工确认节点。

## 6. 数据策略
- 自建 2-3 本模拟空压机手册（规避版权）+ 200 条模拟工单（含故障码/现象/措施/备件/耗时）+ 备件库存模拟；照片报修用实拍/公开设备图。
- 模拟逻辑说明写入合规文档（FAQ Q7 口径）；无真实个人/企业数据，脱敏不适用但声明边界。

## 7. 评测指标
Top-3 诊断命中率 ≥70%（对预置 ground truth 工单集）；备件建议准确率 ≥90%；平均问诊轮次 ≤5；案例沉淀字段完整率 ≥95%；（对照实验）响应时长模拟下降 ≥50%。

## 8. 安全合规口径
仅作辅助参考，不替代专业人员判断与企业安全规范（手册 9.3）；高压电气、压力容器等高危作业输出强制"联系持证人员"提示；数据合规：全部模拟数据并披露生成逻辑（FAQ Q7/Q8）。

## 9. 三档赛事排期
- 初赛（8.16 前）：叙事 PPT+故事线（已完成于保底材料，主线即本项目）
- 复赛（9.3 前）：Web 双端可运行 Demo（客户报修端+工程师工作台）+ 代码仓库 + 运行说明 + 合规文档
- 决赛（9.22）：现场完整旅程演示+失败分支演示（信息缺失→澄清、检索失败→转人工）

## 10. 开源复用物
售后知识库 schema（手册/案例/备件三库）、问诊决策树 DSL、工单案例 CBR 模板、模拟数据生成器。

## 11. 风险与对策
"维修问答机"同质化 → 三件套显性化（工单/备件动作闭环、沉淀飞轮、双端形态）；问诊容错差 → 澄清与转人工节点+失败演示；照片识别不稳 → 降级为"部件定位辅助"叙事。

## 12. 参赛简介（≤500 字，八要素）
**项目名称**：气脉助手 AirFix——空压机售后报修修复沉淀智能体。
**行业赛题**：AI+工业制造。**目标用户**：空压机厂商售后工程师与客户工厂设备管理员。
**核心问题**：报修靠电话、诊断靠专家出差、备件靠翻表、修完知识蒸发。
**解决方案**：四 Agent 协作的单票全旅程闭环——问诊 Agent 多轮交互定位故障（支持拍照识别），知识检索 Agent 融合手册 RAG 与历史案例推理，备件工单 Agent 自动查询库存并起草工单，沉淀 Agent 将维修记录结构化回流知识库，形成越用越准的售后飞轮。
**创新点**：微循环自主、宏流程门禁——Agent 自主完成问诊、检索、备件与工单起草；诊断确认与高危作业始终由人拍板；闭环终点是"动作+知识"而非"答案"。
**开放/复用价值**：开源售后知识库 schema、问诊决策树 DSL、案例模板与模拟数据生成器，可迁移至其他装备行业。
**当前进展**：方案设计完成，双端原型开发中，提交时附演示视频。
