# PRD：M3-A 齐套核算 + 插单冲突解释（P3 计划协同副驾）

> 版本 v1.0 ｜ 2026-08-14 ｜ 锚定场景 S10（评分 90.5，见 `docs/research/场景调研_27选9.md`）

## 1. 场景锚定
S10 机械/汽配二级供应商（90.5）＞ S11 PCB/SMT（87.3）＞ S12 包装印刷（86.1）。
**选 S10**：离散机械/汽配最贴官方六要素叙事；BOM 三层结构适中，便于做依赖图式解释；与 M3-C/M3-B 同厂闭环。落选理由：S11 电子参赛密度高且替代料规则复杂；S12 物料域过简单。

## 2. 产品定位（一句话）
中小机加/汽配厂的计划副驾：求解器管最优化，LLM 管交互与解释——主打插单冲突解释与"动作包"交付，计划权始终在计划员手里。

## 3. 目标用户与痛点
- 用户：计划员/物控（日常使用者）、销售（交期承诺方）、车间主任（执行方）。
- 痛点（量化假设）：插单评估靠 Excel+电话，单次 ≥2 小时；缺料在投产前 1-2 天才暴露；被延订单无解释导致销售与产线互斥。

## 4. Agent 编排（3+1 Agent）
| Agent | 职责（微循环内自主） |
|---|---|
| 齐套核算 Agent | 订单→三层 BOM 展开→毛/净需求→缺口清单（MRP 逻辑，程序化可校验） |
| 排产求解 Agent | OR-Tools 约束求解，输出可行排产与被延订单（LLM 不做数值计算） |
| 冲突解释 Agent | 延期归因（缺哪个料/哪台机满负荷/哪班次人不够）+替代方案对比 |
| 采购联动 Agent | （接 M3-B）缺口→请购草案，形成动作包 |

- **微循环定义**：订单/库存/在途任一变化 → 自动重算齐套 → 求解可行性 → 冲突归因 → 生成动作包（工单+请购+交期草案），全程自主。
- **宏门禁点**：①计划采纳（计划员）②交期承诺（销售确认）③替代料启用（工程确认）。

## 5. 任务闭环 7 步映射（手册 8.2）
输入=订单/插单/库存变化 → 意图理解=变更类型与影响范围 → 任务规划=重算与求解计划 → 能力调用=BOM/库存/在途/产能日历 API+求解器 → 结果交付=可行排产+冲突解释+动作包 → 验证反馈=硬约束零违反校验+延期单数对比基线 → 安全边界=纯建议域声明。

## 6. 数据策略
自建模拟：BOM 三层（成品-组件-原料）×库存×在途×订单 30-50 单×产能日历×技能班次；OR-Tools flexible job-shop 官方示例映射（许可宽松，待核验）；字段与模拟逻辑写入合规文档（FAQ Q7）。

## 7. 评测指标
齐套核算准确率 100%（程序可校验）；排产硬约束违反 0；延期订单数较 FIFO 基线下降 ≥15%；插单全流程响应 ≤30 秒；冲突解释采纳率（人工评分）。

## 8. 安全合规口径
纯计划建议系统，不写真实 ERP；计划采纳与承诺交期由人决定（手册 9.3：不替代专业人员判断）；LLM 与求解器契约公开（技术透明）。

## 9. 三档赛事排期
- 初赛（8.16 前）：架构图+LLM/求解器契约图（保底 PPT 第 6 页模板可复用）
- 复赛（9.3 前）：齐套核算+插单冲突解释一条链可运行（含甘特与解释面板）
- 决赛（9.22）：交互式插单演示+与 M3-C/M3-B 同厂联动（风险→缺口→请购）

## 10. 开源复用物
制造模拟数据生成器、齐套核算引擎封装、冲突解释 Prompt 模板、依赖图可视化组件。

## 11. 风险与对策
"与 APS 比呢"质疑 → 定位中小厂用不起 APS 的轻量入口+自然语言交互；"LLM 排产不靠谱"质疑 → 契约显性：LLM 不算数；排产输出被误用 → 界面强制"采纳确认"门禁。

## 12. 参赛简介（≤500 字，八要素）
**项目名称**：齐途 QiPlan——机加厂齐套核算与插单冲突解释智能体。
**行业赛题**：AI+工业制造。**目标用户**：中小机械/汽配厂计划员、物控与销售。
**核心问题**：插单靠电话与 Excel 评估，缺料发现晚，被延订单说不清原因。
**解决方案**：LLM×求解器分工的计划副驾——齐套核算 Agent 做三层 BOM 展开与缺口清单；排产求解 Agent 用约束求解生成可行排产；冲突解释 Agent 归因每张被延订单（缺哪个料、哪台机满载）并给出替代方案；采购联动 Agent 把缺口变成请购草案，最终交付"工单+请购+交期"动作包。
**创新点**：求解器管最优化、LLM 管交互与解释的清晰契约；主打传统 APS 最缺的插单冲突解释；微循环自主重算，计划采纳与交期承诺始终由人拍板。
**开放/复用价值**：开源制造模拟数据生成器、齐套引擎与解释模板，中小厂可直接复用。
**当前进展**：方案与数据模型设计完成，原型开发中，提交时附演示。
