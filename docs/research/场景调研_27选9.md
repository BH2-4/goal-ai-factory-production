# 第一部分：P2 装备售后全旅程（S01-S09）

## M2-A 报修-修复-沉淀主链

### S01 空压机厂商售后远程支持（M2-A ①）
- **场景**：中小螺杆空压机厂商（客户为各行业工厂动力车间）：客户报修（照片/语音/故障码）→ 远程问诊 → 手册/案例检索 → 备件查询 → 工单派发 → 指导维修 → 案例回写。
- **用户/痛点**：厂商售后工程师与客户设备管理员；服务网点少、专家差旅成本高、SLA 难达标、耗材滤芯/油品更换类工单占比高且重复。
- **数据可得**：自建模拟故障码手册+200 条工单（版权干净）4/5；**模板可得**：开源 CMMS（Snipe-IT/openMAINT）+ 工单 schema 4/5 → G1 ✅
- **竞争密度**：中高（通用"设备维修问答"多；打穿备件+工单+回写的少）
- **微循环/门禁**：微循环=单票报修全链（问诊→检索→备件→工单→指导）自主跑完；门禁=诊断确认（工程师）、高压电气/大修转持证人员、案例入库存档审核
- **G2**：可重构 ｜ **打分**：D1 5 / D2 4.5 / D3 4.5 / D4 4 / D5 4.5 / D6 4 → **总分 89.8**

### S02 注塑机厂商售后支持（M2-A ②）
- **场景**：注塑机厂商（液压/温控/控制器三类故障域）远程诊断与保养提醒。
- **用户/痛点**：注塑厂设备科；停机损失大、液压故障诊断依赖老师傅。
- **数据可得**：自建模拟手册+工单 4.5；**模板可得**：CMMS 4 → G1 ✅
- **竞争密度**：中（注塑 AI 参赛者可能撞车工艺方向）
- **微循环/门禁**：同 S01；门禁=机械/液压安全作业转持证
- **G2**：可重构 ｜ **打分**：D1 4.5 / D2 4.5 / D3 4.5 / D4 3.5 / D5 4 / D6 4 → **总分 84.0**

### S03 数控机床厂商售后支持（M2-A ③）
- **场景**：机床报警码（类 FANUC/Siemens 体系）远程诊断与保养工单。
- **用户/痛点**：机加工厂设备科；报警码数千条、诊断知识在厂商专家手里。
- **数据可得**：自建模拟报警码库（真实码表有版权，需自写）3.5；**模板可得**：CMMS 4 → G1 ✅

- **微循环/门禁**：同 S01；门禁=电气柜作业/精度调整转授权人员
- **G2**：可重构 ｜ **打分**：D1 4.5 / D2 4.5 / D3 4 / D4 3.5 / D5 4 / D6 4 → **总分 82.5**

**M2-A 小结**：S01 空压机 89.8 ＞ S02 84.0（差 5.8）→ 锚定 **S01**。理由：IoT 远程监控在空压机行业渗透率最高（物联网空压机是标配），售后服务合同模式成熟，且与 M2-B/M2-C 同行业形成协同。

## M2-B 批次故障哨兵

### S04 空压机机队批次故障监测（M2-B ①）
- **场景**：厂商侧远程监控平台盯数千台分布客户机队：工单/告警流持续聚类 → 同型故障率异常上升/同批次部件集中失效 → 影响面清单+售后 8D 初稿 → 服务通报建议。
- **用户/痛点**：厂商质量/售后负责人；批次问题发现靠客户投诉倒逼，召回决策缺数据支撑。
- **数据可得**：200+ 模拟工单预埋批次模式 + 类 AI4I 遥测 4.5；**模板可得**：8D 报告模板（行业通用）+ 聚类/时序开源 5 → G1 ✅
- **竞争密度**：低（跨工单哨兵视角预计无同类）
- **微循环/门禁**：微循环=持续值守（聚类→模式识别→起草）；门禁=是否发服务通报/召回、客户通知（厂商管理层拍板）
- **G2**：可重构 ｜ **打分**：D1 5 / D2 5 / D3 4.5 / D4 5 / D5 4.5 / D6 5 → **总分 97.2（全场最高）**

### S05 光伏逆变器机队批次退化监测（M2-B ②）

- **用户/痛点**：运维商；组串级失效分散难归因。

# 第二部分：P3 计划协同副驾（S10-S18）

## M3-A 齐套核算 + 插单冲突解释

### S10 机械/汽配二级供应商齐套与插单（M3-A ①）

- **用户/痛点**：计划员/物控；插单靠 Excel+电话、缺料发现晚、冲突解释不清导致销售与产线互斥。
- **数据可得**：自建模拟（BOM 3 层×库存×在途×订单 30-50 单×产能日历）4.5；**模板可得**：OR-Tools flexible job-shop 官方示例 + Odoo MRP 逻辑参考 4.5 → G1 ✅
- **竞争密度**：中（做排产的不少；主打"冲突解释"的少）
- **微循环/门禁**：微循环=需求变化→重算齐套→可行性→冲突归因→动作包；门禁=计划采纳、交期承诺（计划员/销售拍板）
- **G2**：可重构（纯建议域）｜ **打分**：D1 5 / D2 4 / D3 4.5 / D4 4 / D5 5 / D6 5 → **总分 90.5**
