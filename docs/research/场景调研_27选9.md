# 第一部分：P2 装备售后全旅程（S01-S09）

## M2-A 报修-修复-沉淀主链

### S01 空压机厂商售后远程支持（M2-A ①）
- **场景**：中小螺杆空压机厂商（客户为各行业工厂动力车间）：客户报修（照片/语音/故障码）→ 远程问诊 → 手册/案例检索 → 备件查询 → 工单派发 → 指导维修 → 案例回写。
- **用户/痛点**：厂商售后工程师与客户设备管理员；服务网点少、专家差旅成本高、SLA 难达标、耗材滤芯/油品更换类工单占比高且重复。
- **数据可得**：自建模拟故障码手册+200 条工单（版权干净）4/5；**模板可得**：开源 CMMS（Snipe-IT/openMAINT）+ 工单 schema 4/5 → G1 ✅
- **竞争密度**：中高（通用"设备维修问答"多；打穿备件+工单+回写的少）
- **微循环/门禁**：微循环=单票报修全链（问诊→检索→备件→工单→指导）自主跑完；门禁=诊断确认（工程师）、高压电气/大修转持证人员、案例入库存档审核
- **G2**：可重构 ｜ **打分**：D1 5 / D2 4.5 / D3 4.5 / D4 4 / D5 4.5 / D6 4 → **总分 89.8**

### S02 注塑机厂商售后支持（M2-A ②）
- **场景**：注塑机厂商（液压/温控/控制器三类故障域）远程诊断与保养提醒。
- **用户/痛点**：注塑厂设备科；停机损失大、液压故障诊断依赖老师傅。
- **数据可得**：自建模拟手册+工单 4.5；**模板可得**：CMMS 4 → G1 ✅
- **竞争密度**：中（注塑 AI 参赛者可能撞车工艺方向）
- **微循环/门禁**：同 S01；门禁=机械/液压安全作业转持证
- **G2**：可重构 ｜ **打分**：D1 4.5 / D2 4.5 / D3 4.5 / D4 3.5 / D5 4 / D6 4 → **总分 84.0**

### S03 数控机床厂商售后支持（M2-A ③）
- **场景**：机床报警码（类 FANUC/Siemens 体系）远程诊断与保养工单。
- **用户/痛点**：机加工厂设备科；报警码数千条、诊断知识在厂商专家手里。
- **数据可得**：自建模拟报警码库（真实码表有版权，需自写）3.5；**模板可得**：CMMS 4 → G1 ✅
- **竞争密度**：中高（机床故障诊断是常见选题）
- **微循环/门禁**：同 S01；门禁=电气柜作业/精度调整转授权人员
- **G2**：可重构 ｜ **打分**：D1 4.5 / D2 4.5 / D3 4 / D4 3.5 / D5 4 / D6 4 → **总分 82.5**

**M2-A 小结**：S01 空压机 89.8 ＞ S02 84.0（差 5.8）→ 锚定 **S01**。理由：IoT 远程监控在空压机行业渗透率最高（物联网空压机是标配），售后服务合同模式成熟，且与 M2-B/M2-C 同行业形成协同。

## M2-B 批次故障哨兵

### S04 空压机机队批次故障监测（M2-B ①）
- **场景**：厂商侧远程监控平台盯数千台分布客户机队：工单/告警流持续聚类 → 同型故障率异常上升/同批次部件集中失效 → 影响面清单+售后 8D 初稿 → 服务通报建议。
- **用户/痛点**：厂商质量/售后负责人；批次问题发现靠客户投诉倒逼，召回决策缺数据支撑。
- **数据可得**：200+ 模拟工单预埋批次模式 + 类 AI4I 遥测 4.5；**模板可得**：8D 报告模板（行业通用）+ 聚类/时序开源 5 → G1 ✅
- **竞争密度**：低（跨工单哨兵视角预计无同类）
- **微循环/门禁**：微循环=持续值守（聚类→模式识别→起草）；门禁=是否发服务通报/召回、客户通知（厂商管理层拍板）
- **G2**：可重构 ｜ **打分**：D1 5 / D2 5 / D3 4.5 / D4 5 / D5 4.5 / D6 5 → **总分 97.2（全场最高）**

### S05 光伏逆变器机队批次退化监测（M2-B ②）
- **场景**：电站逆变器机队批量衰减/批次故障监测。
- **用户/痛点**：运维商；组串级失效分散难归因。
- **数据可得**：公开光伏发电数据集可用 4（待核验具体许可）；**模板可得**：时序异常检测开源 4 → G1 ✅
- **竞争密度**：中（能源 AI 选题多，会稀释"装备售后"叙事）
- **微循环/门禁**：微循环=持续监测；门禁=现场处置决策
- **G2**：可重构 ｜ **打分**：D1 4 / D2 5 / D3 4 / D4 4.5 / D5 4.5 / D6 4.5 → **总分 88.0**

### S06 电梯机队批次故障监测（M2-B ③）
- **场景**：电梯维保公司机队故障模式监测（困人/停梯聚集）。
- **用户/痛点**：维保公司；监管强、应急处置压力大。
- **数据可得**：模拟困人/故障记录 4；**模板可得**：维保工单开源 3.5 → G1 ✅
- **竞争密度**：低
- **微循环/门禁**：微循环=监测聚类；门禁=依规处置（法定维保流程），**监管门禁多且刚性 → 部分可重构**
- **G2**：部分可重构（监管流程占比高）｜ **打分**：D1 4 / D2 5 / D3 4 / D4 4.5 / D5 3.5 / D6 4 → **总分 84.7**

**M2-B 小结**：S04 97.2 ＞ S05 88.0（差 9.2）→ 锚定 **S04**。与 S01 同数据域（工单+遥测），复用 M2-A 管线；根因引擎复用 P1 的 M1-A 模块。

## M2-C 设备档案自动建立

### S07 空压机装机验收档案数字化（M2-C ①）
- **场景**：厂商装机/调试/验收单（手写+拍照+PDF 混排）→ 解析 → 结构化设备档案+保养基线 → 自动纳入售后监测与保养提醒。
- **用户/痛点**：厂商客服/档案管理员；装机单据格式杂乱、档案滞后、保内保外判定纠纷。
- **数据可得**：自造 20-30 份多格式样例（版权干净）4.5；**模板可得**：PaddleOCR/LayoutLM 系开源文档理解 4.5 → G1 ✅
- **竞争密度**：低（"给 AI 铺数据"的场景化作品稀缺）
- **微循环/门禁**：微循环=解析→抽取→置信度→预填；门禁=档案定稿入库（工程师确认）
- **G2**：可重构 ｜ **打分**：D1 4 / D2 3.5 / D3 4.5 / D4 4.5 / D5 5 / D6 3.5 → **总分 83.4**

### S08 注塑机搬迁/移机档案迁移（M2-C ②）
- **场景**：二手/移机注塑机档案重建与差异核对。
- **用户/痛点**：设备部；频次低（痛点中低频）。
- **数据可得**：自造样例 4.5；**模板可得**：OCR 开源 4 → G1 ✅
- **竞争密度**：低
- **微循环/门禁**：同 S07
- **G2**：可重构 ｜ **打分**：D1 3.5 / D2 3.5 / D3 4.5 / D4 4 / D5 5 / D6 3.5 → **总分 78.9**

### S09 二手设备评估档案数字化（M2-C ③）
- **场景**：二手设备交易平台/评估机构的铭牌、检验报告、维修记录结构化。
- **用户/痛点**：评估师；信息不透明、估值依赖经验。
- **数据可得**：公开二手listing 风格样例可造 4；**模板可得**：OCR 4 → G1 ✅
- **竞争密度**：低-中
- **微循环/门禁**：微循环=解析→预填；门禁=估值结论（评估师）
- **G2**：可重构 ｜ **打分**：D1 3.5 / D2 3.5 / D3 4 / D4 4.5 / D5 5 / D6 4 → **总分 80.1**

**M2-C 小结**：S07 83.4 ＞ S09 80.1 ＞ S08 78.9 → 锚定 **S07**。与 S01/S04 构成"装机→运维→哨兵"同行业闭环。
